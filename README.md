## ✨ Возможности

### 🔄 Мониторинг площадок (Перекуп)

| Функция | Описание |
|---------|----------|
| **Мониторинг** | Kufar, OLX, Avito и другие площадки |
| **Фильтрация** | По цене (мин/макс) и региону |
| **Черный список** | Исключение слов ("разбит", "не работает") |
| **Порог снижения** | Уведомления только при значительном падении цены |
| **Только с фото** | Фильтр по наличию изображений |
| **Тестовый поиск** | Просмотр последнего объявления по запросу |
| **Пауза/Возобновление** | Временное отключение поиска |
| **Групповой режим** | Отправка в каналы и группы |
| **Аналитика рынка** | Сравнение цены со средней по рынку |

### 🛒 Магазин цифровых товаров

|---------|----------|

| **История покупок** | Все покупки пользователя |

| **Валидация** | Проверка изображений и данных |

## 🚀 Установка

### Требования

- Python 3.10+
- Windows / Linux / macOS

### Шаги

1. **Клонировать репозиторий:**
   ```bash
   git clone https://github.com/ana-username/wellbot.git
   cd wellbot
Создать виртуальное окружение:

bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate
Установить зависимости:

bash
pip install -r requirements.txt
Создать .env файл:

bash
cp .env.example .env
Заполните BOT_TOKEN и ADMIN_ID.

Запустить бота:

bash
python main.py
Или на Windows через run.bat.

⚙️ Конфигурация (.env)
Переменная	По умолчанию	Описание
BOT_TOKEN	—	Токен бота от @BotFather
ADMIN_ID	0	Telegram ID администратора
ADMIN_IDS	—	Список админов через запятую
TRIAL_DAYS	3	Дней тестового периода
CHECK_INTERVAL	30	Интервал мониторинга (сек)
RATE_LIMIT_PER_SEARCH	2.5	Задержка между запросами (сек)
PARSER_TIMEOUT	15	Таймаут парсера (сек)
PARSER_RETRY_ATTEMPTS	3	Повторных попыток парсера
DATABASE_PATH	data/wellbot.db	Путь к SQLite БД
LOG_LEVEL	INFO	Уровень логирования
LOG_FILE	logs/wellbot.log	Путь к файлу логов

🛠 Технологии
aiogram 3.x — асинхронный Telegram Bot API

aiosqlite — асинхронная работа с SQLite

aiohttp — HTTP-клиент для парсинга

BeautifulSoup4 + lxml — парсинг HTML/JSON

python-dotenv — загрузка конфигурации

pydantic — валидация данных
