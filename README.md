# 🤖 WellBoT — Telegram-бот для мониторинга объявлений

Коммерческий Telegram-бот, который отслеживает новые объявления на [WellBoT](https://www.kufar.by) и моментально уведомляет пользователей о выгодных предложениях и снижениях цен.

## ✨ Возможности

### Для пользователей
- **➕ Создание поисков** — по пресетам (iPhone, Ноутбуки, PS5, Велосипеды) или своему запросу
- **💰 Фильтрация по цене** — минимальная и максимальная цена в BYN
- **📍 Выбор региона/города** — все области и крупные города Беларуси
- **📊 Анализ рынка** — оценка цены объявления относительно средней по выборке (ниже/выше/средняя)
- **✏️ Редактирование поисков** — изменение названия, цен, blacklist, порога снижения цены
- **⏸ Пауза/возобновление** — временное отключение поиска без удаления
- **🚫 Blacklist (исключения)** — фильтрация по словам («разбит», «не работает», «запчаст»)
- **📉 Порог снижения цены** — уведомления о снижении только если разница превышает заданную сумму
- **📨 Multi-photo** — отправка до 10 фотографий объявления (media group)
- **📩 Тестовый поиск** — мгновенный показ последних объявлений по пресету
- **📊 Статистика** — количество найденных объявлений, активных поисков, рефералов
- **🎁 Реферальная программа** — +1 день подписки за каждого приглашённого друга
- **🎟 Промокоды** — активация бесплатных дней подписки
- **💳 Тарифные планы** — оплата через Telegram Stars

### Для администратора
- **⚙️ Админ-панель** — доступ по Telegram ID
- **🎁 Выдача подписки** — по ID или @username
- **📊 Статистика бота** — пользователи, поиски, объявления
- **📢 Рассылка** — отправка сообщения всем пользователям
- **🚫 Бан/Разбан** — блокировка пользователей
- **🎟 Управление промокодами** — создание, просмотр, удаление
- **📱 Уведомление при запуске** — админ получает сообщение о старте бота

### Технические особенности
- **Ротация User-Agent** — 5 разных UA для защиты от бана WellBoT
- **Retry-логика парсера** — повторные попытки при 403/ошибках сети
- **Rate limiting** — настраиваемая задержка между запросами к WellBoT
- **Очередь отправки** — защита от Telegram flood-банов с обработкой `RetryAfter`
- **Ротация логов** — файлы до 2 МБ, 5 бэкапов
- **Миграции БД** — автоматическое добавление новых колонок к существующей БД
- **Сортировка по ad_id** — реальные новые объявления (а не bumped-поднятые)
- **Fetch ad details** — загрузка описания и продавца со страницы объявления
- **Индекс БД** — быстрый поиск дубликатов `sent_ads(ad_id, search_id)`
- **Автоочистка БД** — периодическое удаление старых записей `sent_ads`
- **Меню бота** — кнопка ≡ в чате со списком команд (не нужно писать /start)

## 🚀 Установка

### Требования
- Python 3.10+
- Windows / Linux / macOS

### Шаги

1. **Клонировать проект:**
   ```bash
   git clone <repo-url>
   cd wellbot
   ```

2. **Создать виртуальное окружение и установить зависимости:**
   ```bash
   python -m venv venv
   # Windows:
   venv\Scripts\activate
   # Linux/macOS:
   source venv/bin/activate

   pip install -r requirements.txt
   ```

3. **Создать `.env` файл:**
   ```bash
   cp .env.example .env
   ```
   Заполните `BOT_TOKEN` и `ADMIN_ID` (ваш Telegram ID).

4. **Запустить бота:**
   ```bash
   python src/main.py
   ```
   Или на Windows через `run.bat` (двойной клик).

## ⚙️ Конфигурация (.env)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | Токен бота от [@BotFather](https://t.me/BotFather) |
| `ADMIN_ID` | `0` | Telegram ID администратора |
| `TRIAL_DAYS` | `3` | Дней тестового периода |
| `CHECK_INTERVAL` | `30` | Интервал мониторинга (сек) |
| `RATE_LIMIT_PER_SEARCH` | `2.5` | Задержка между запросами к WellBoT (сек) |
| `PARSER_TIMEOUT` | `15` | Таймаут парсера (сек) |
| `PARSER_RETRY_ATTEMPTS` | `3` | Кол-во повторных попыток парсера |
| `PARSER_RETRY_DELAY` | `2.0` | Задержка между повторами (сек) |
| `DATABASE_PATH` | `data/wellbot.db` | Путь к SQLite БД |
| `LOG_LEVEL` | `INFO` | Уровень логирования |
| `LOG_FILE` | `logs/wellbot.log` | Путь к файлу логов |
